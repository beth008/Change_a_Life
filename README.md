**SETUP INSTRUCTIONS**
1. Firstly make sure you have the download or clone of this project's repository.
2. Open the project folder in VS Code.
3. Ensure the HTML,CSS and JS files are in thier correct locations.
4. Right click on index.html and Open it with a live server whereby it will open in a browser(most probably your defualt browser) to use the application.
5. You can read through the home page and the about page but on the Team page there will be a form that can register you to join the team with valid inputs.
6. And then for the Add Project one can use it to input ant project ideas of their choice and various people can view them by pressing the link below(View Projects).
7. When one click on that link(View Projects) they will be able to see the projects that various people have suggested.
